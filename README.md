# オークション作戦ノート

ヤフオクで「いくらまで入札するか」「いくらで売るか」を決めるための計算ツールです。
`index.html` をブラウザで開くだけで使えます(インストール不要)。

## できること

- **相場を調べる**
  - ほしい物を検索ワードで登録(ほしい物リスト)
  - ワードごとにヤフオクの落札相場ページへのリンクを作成
  - ヤフオクのページで押す「取り込みボタン」(ブックマーク)で内容をコピーし、貼り付けるだけで自動振り分け・分析
  - 落札価格を読み取って中央値・分布グラフを表示
  - 「最安値付近で狙う/安く狙う/標準/確実に取る」の4段階(過去の落札の約10%・25%・50%・75%の位置)で入札額を提案し、入札タブへ送る
  - グラフ下の赤いスライダーで上限(赤線)を動かし、それより高い落札価格を入札額の計算から除く(初期位置は極端に高い値段だけを外す自動設定。相場の表示には含める)
  - 調べた日ごとの相場の変化を記録
- **入札する**
  - 予算と送料から、入札してよい上限額を計算
  - 転売目的なら、売値・手数料・送料・ほしい利益から、仕入れの上限額を計算
  - 現在価格から、次に入札できる最低額(入札単位)を表示
- **出品する**
  - 落札価格・仕入れ値・送料・手数料率から、手元に残る利益と利益率を計算
  - ほしい利益から、最低いくらで売ればよいかを逆算

入力した数字は、使っているブラウザの中だけに保存されます(外部には送信しません)。

## 方針

- 自動入札や自動データ取得(スクレイピング)は作りません(ヤフオクの利用規約に配慮)
- 新着の監視・通知は、ヤフオク公式の「検索条件の保存」と通知機能を使います

## 今後の予定

1. 第1段階:入札・出品の計算(完了)
2. 第2段階:相場分析(完了。読み取り精度は実データで調整予定)
3. 第3段階:監視ガイド、データ保存、使い勝手の改善

## 決定事項(相談で決まったこと)

- 高額品は自動で外さない。極端に安い値段だけ自動で外す
- 入札額の提案は、グラフの赤線(スライダー)より高い値段を除いて計算する。初期位置は自動(極端に高い値段だけ外す)、商品ごとに保存
- 中央値・最安・最高の表示には高い値段も含める
- 平均は表示しない(計算に使っていないため)
- 「最安値付近で狙う」は、極端に安い値段を除いたうえでの約10%の位置とする
- 最初から入っている「FUJIFILM X-T3 ボディ」の値段は動作確認用の架空の例で、実際の相場ではない
